# v140: Prompt-Sensitivity Threshold Robustness

## 1. Question

v134/v136 used the frozen rule:

```text
cphi_score > 0 -> prompt conditional
cphi_score <= 0 -> prompt invariant
```

This produced only one positive head. The result is not proof that prompt
sensitivity is absent. It means the original residual semantic/paraphrase
log-ratio is mostly negative. The same profiles also show that CPHI is highly
correlated with direct changes in Q, native output, and current K. A threshold
cannot repair that confound by itself.

v140 answers two narrower questions:

1. does a thresholded split transfer to held-out prompt families;
2. how strongly do class membership and class count change when the threshold
   changes?

v140 is CPU-only and does not generate videos.

## 2. Candidate scores

The analyzer evaluates four frozen scores:

```text
raw_cphi       = cphi_score
query_adjusted = cphi_score - query_score
native_adjusted = cphi_score - native_score
key_adjusted   = cphi_score - current_key_score
```

`query_adjusted` is the main candidate. Both terms are semantic/paraphrase log
ratios. Its zero threshold asks:

```text
Does the prompt intervention change history interaction more than it changes Q?
```

This score was suggested by the committed v136 results, where a post-hoc
calculation gave a nondegenerate split. v140 treats that observation as a new
hypothesis and evaluates it on held-out families; it is not retroactively a
passed v136 result.

## 3. Discovery and validation

The 16 controlled subject families are split before threshold fitting:

```text
discovery: even family indices
validation: odd family indices
```

Every family contributes all eight controlled factors. The split therefore
tests transfer across identities and scenes while preserving factor coverage.

Layer 0 is excluded from threshold fitting because its self-attention occurs
before prompt information has propagated through a transformer block. Its
near-zero response is structural, not evidence for a semantic class. Layer 0
is forced to the invariant/stable class in exported maps.

## 4. Thresholds

The primary threshold remains zero. It has a declared meaning for each score
and does not use PF labels, desired class counts, VBench, or video review.

Two thresholds are fitted on discovery families only:

```text
Otsu
two-component GMM intersection
```

They are diagnostics. They can become candidates only if the frozen threshold
transfers to validation.

The analyzer also sweeps discovery percentiles from 0 to 100 in increments of
5. This sweep is not a model-selection procedure. It exposes how arbitrary
threshold movement changes:

- validation positive count;
- discovery/validation label agreement;
- positive-set Jaccard;
- minority class fraction;
- fraction of validation heads close to the decision boundary.

## 5. Frozen zero-threshold gate

A score passes only when all conditions hold on layers 1-29:

```text
discovery/validation head-rank Spearman >= 0.60
zero-label agreement >= 0.80
validation minority fraction >= 0.05
heads within 0.1 discovery-IQR of zero <= 0.20
```

Passing this gate supports a reproducible binary taxonomy. It does not show
that routing the two classes differently improves generated video.

## 7. Decision rule

Use the result in this order:

1. inspect the query-adjusted zero-threshold gate;
2. inspect discovery/validation rank and label stability;
3. inspect the threshold sweep for boundary concentration;
4. inspect factor-specific signs;
5. use Otsu/GMM only as diagnostics.

If query-adjusted zero passes, freeze that definition before any video routing
experiment. If it fails, do not select a percentile that happens to resemble
PF or the old v98 304/56 count. Use the stronger full-prompt intervention in
v141 or keep prompt response continuous.
